# Ivoire Mobility

A pilot-ready MVP for a Côte d’Ivoire mobility platform covering customer booking, driver operations, and admin oversight.

## Stack

- Next.js 14 web app
- Express + TypeScript API
- Tailwind CSS
- Shared demo data and mock business logic

## Quick start

```bash
npm install
npm run dev
```

Open the following in your browser:

- Web app: http://localhost:3000
- API: http://localhost:4000/api/health

## Demo data

All business data in this repository is clearly marked as demonstration data and should not be treated as a production or regulatory-compliant deployment.

## Notes

This is a realistic MVP for a pilot in Abidjan and surrounding zones. It intentionally avoids claiming real payment integrations, GPS data, or legal compliance without the required reviewed setup.
