# Ivoire Mobility

This repository contains an MVP architecture and working demo for the Ivoire Mobility platform.

## Included
- Customer web app with route planning flow
- Driver dashboard
- Admin operations dashboard
- Express TypeScript API with mock data and booking endpoints
- Shared types and demo data

## Quick start

```bash
npm install
npm run dev
```

Then open:
- Web app: http://localhost:3000
- API: http://localhost:4000

## Environment

Create `.env` files as needed for the frontend and API. The included demo is designed to run without external services.

## Notes

This is a realistic MVP for pilot deployment in Abidjan, with mock data clearly labeled as demonstration data.
